# 05 — VEHICLES, TRAFFIC & LIVING OPEN WORLD

## Vehicle interaction
- approach
- open door
- enter driver/passenger
- remove hostile driver where mission rules allow
- take vehicle
- break window as a game interaction
- unlock/hotwire abstraction where appropriate
- start engine
- exit
- exit while moving / jump-out with risk
- shoot from vehicle
- seat switching

## Vehicle damage states
Clean → scratches → dent → glass crack → glass break → door damage → hood deformation → wheel/tire damage → engine smoke → fire → destroyed.

Use Chaos only where it adds meaningful interaction; use state swaps and optimized debris for secondary assets.

## Civilian world states
Normal → Concerned → Panic → Flee → Cover → Evacuate → Recovery.

Civilian actions:
walk, talk, phone, text, drink/eat, shop, carry bags, sit, wait, work, enter/exit shops and vehicles, cross roads, greet, take photos, run, panic, cower, hide, assist injured NPCs.

## Crisis / security response
Threat levels:
0 Normal
1 Local alert
2 Patrol response
3 Armed response
4 Tactical response
5 Major lockdown

Escalation should depend on detection/reporting through witnesses, cameras, sensors or confirmed security observation rather than magical omniscience.
