# 15 — REFERENCES, LEGAL CONTENT RULES & SOURCE LINKS

## Original-content rule

References may inform:
- pacing;
- genre conventions;
- responsiveness;
- feature categories;
- control philosophy;
- production techniques.

The project must not copy:
- proprietary source code;
- protected characters;
- distinctive level layouts;
- logos;
- dialogue;
- audio;
- ripped textures/models/animations;
- leaked assets;
- proprietary UI/iconography.

All production assets must be original, commissioned, generated with appropriate rights or properly licensed.
