# 06 — WORLD & ENVIRONMENT BIBLE: JEDDAH / RED SEA

## Authenticity rule

The world must read as **Jeddah**, not a generic Dubai/Riyadh/Gulf sci-fi composite.
Near-future additions must grow from believable Jeddah.

## World Partition districts
- JED_Corniche
- JED_AlBalad
- JED_Downtown
- JED_NorthUrban
- JED_Highway
- JED_Port
- JED_Industrial
- JED_Marina
- JED_Residential
- JED_Outskirts
- JED_Rooftops
- JED_Underground

Each district needs:
architecture kit, roads, props, population profile, traffic profile, weather profile, security level, missions, interiors, world events and Data Layers.

## Al-Balad modular kit
Rawasheen, old plaster/stone walls, wood screens, shopfronts, Arabic signage, stalls, lanterns, wiring, AC units, doors, windows, rooftops, balconies, workshops and alleys.

Material states:
NORMAL / AGED / WAR-DAMAGED.

## Corniche
Sea wall, walkway, roads, palms, lighting, cafés, barriers, marina, seating, coastal vegetation, traffic, emergency layers.

States:
day, sunset, night, storm, combat, evacuation.

## Port
Container yards, gantry cranes, loading platforms, wet asphalt, ladders, bollards, mooring ropes, warehouses, customs, patrol craft, RHIBs, cargo shipping, checkpoints.

## Roads
Arabic/English signs, markings, lights, traffic cameras, barriers, bollards, curbs, drains, manholes, streetlights, crossings, bridges and tunnels.

## Interiors
Apartment, office, command room, clinic/lab, shop, market, warehouse, parking, hotel lobby, military/security area, rooftop room.

## Red Sea / maritime world
Offshore platforms, naval routes, islands, carrier-style fictional naval operations, maritime installations, damaged offshore structures and storm/night infiltration spaces.

## Water requirements
Waves, spray, shoreline collision, rotor wash, explosion splash, projectile impacts, wakes, storm variation and flooded-interior visual states.
