# 09 — UI, UX & MOTION GRAPHICS

## Color semantics

Brand / presentation:
- Black
- Burnished Gold
- Gunmetal
- Off-white

Gameplay:
- neutral/info = white/cyan
- friendly = cyan/green
- warning = amber
- hostile/danger = red
- gold = rank, achievement, premium identity, mission-complete accents

Do not flood the gameplay HUD with gold.

## Infantry HUD
Compass, objective, ammo, fire mode, health state, armor, grenade/equipment, context action, squad state.

## Vehicle HUD
Speed, gear, RPM abstraction, damage, vehicle weapon/ammo, occupants, route, threat.

## Helicopter HUD
Altitude, heading, speed, pitch/roll, target, weapon, countermeasures, damage.

## Drone HUD
Signal, battery, zoom, target, thermal, range, mark/hack, return.

## Context-specific overlays
Port / maritime tactical
Mech threat-analysis / weak points
Rooftop recon / scan
Highway vehicle combat
Evacuation civilian count and route
Corniche air-threat state
Al-Balad escort
Offshore structural/flood state
Rooftop insertion rope/team status

## Scanner / network look
Desaturated world, cyan/blue edge/semantic highlighting, device labels, signal state, distance and threat overlays.
Visual identity must be original “Saudi tactical command network,” not copied from another game.

## Diegetic UI
Wrist device, vehicle dashboard, helmet display, command table, phone/tablet, wall displays, drone interface.

## Main menu
3D command-center menu:
Campaign → command map
Loadout → weapon bench
Operators → squad area
Vehicles → hangar
Settings → terminal

## Loadout
Full 3D character, rotatable.
Slots:
Primary, Secondary, Melee, Lethal, Tactical, Armor, Helmet, Device, Skill/Perk, Support.

## Weapon bench
Camera focuses on selected attachment; animated detach/install/inspect; display balance metrics.

## Motion language
- vector trace
- corner-bracket draw
- grid reveal
- signal sweep
- target acquire
- radar pulse
- hex expansion
- data stream
- map triangulation
- threat pulse

Typical micro-animation: 120–280 ms.
Mission transitions: ~0.8–2 s depending on context.

## UI sound language
soft relay click, digital chirp, low tactical pulse, radio texture, map lock, confirmation, warning and threat tones.
Avoid sci-fi laser clichés.
