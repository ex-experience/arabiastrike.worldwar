# 13 — PC INPUT & CONTROL SYSTEM

## Principle
PC-first, fully remappable, raw-mouse friendly, hold/toggle options, independent driving sensitivity, seamless keyboard/mouse ↔ gamepad switching.

Input presets:
1. EX Hybrid
2. Military FPS
3. Open World
4. Cyber Action
5. Stealth Hacker
6. Custom

## Recommended EX Hybrid — On Foot
| Action | Default |
|---|---|
| Move | W/A/S/D |
| Look | Mouse |
| Fire / attack | Left Mouse |
| ADS / guard | Right Mouse |
| Sprint | Left Shift |
| Tactical sprint | Double Shift or configurable |
| Jump / vault / mantle | Space |
| Crouch / slide | Left Ctrl |
| Prone | Z |
| Lean left | Q |
| Lean right | E |
| Reload | R |
| Interact | F |
| Melee | V |
| Grenade | G |
| Tactical equipment | X |
| Primary/secondary/sidearm/melee | 1/2/3/4 |
| Weapon cycle | Mouse Wheel |
| Weapon wheel | Tab |
| Ping | Middle Mouse |
| Scan / hack | Caps Lock |
| Device / phone | T |
| Camera | C |
| Map | M |
| Inventory | I |
| Pause | Esc |

Contextual:
Ctrl standing → crouch
Ctrl while sprinting → slide
Z → prone
Sprint + prone binding → dive-to-prone if enabled
