# 01 — GAME VISION, IP & EXPERIENCE PILLARS

## Positioning

A Saudi-born premium action franchise with global readability, regional authenticity and expandable transmedia potential.

The project must not be described internally as a clone. Use:
> **Original implementation targeting feature-class parity, responsiveness and production quality.**

## Core gameplay loop
`BRIEF → DEPLOY → ENGAGE → ESCALATE → EXTRACT`

### Brief
Command-table intelligence, squad selection, loadout, routes, civilians, weather, threat level, support and extraction.

### Deploy
Helicopter, vehicle, boat, rooftop insertion, foot infiltration, convoy or urban spawn depending on mission.

### Engage
Infantry, stealth, hacking, cover, vehicles, squad tactics, civilians and dynamic encounter systems.

### Escalate
Security/hostile response, reinforcements, air/drone threat, destruction, environmental change, wanted/threat escalation.

### Extract
Reach extraction, hold zone, rescue/escort, vehicle escape, helicopter/boat extraction or transition to open-world recovery.

## Design differentiation
The strongest version of the IP is not “COD/GTA in Jeddah.”
It is:
> An open-world Saudi military thriller beginning with a war on Jeddah and revealing an interconnected conflict across land, sea, air and network space, with seamless transitions between civilian life, tactical combat, special operations, vehicles and strategic warfare.
