# AAA-Style Acceptance Gates

"AAA" is treated as a quality target, not a claim created by engine choice.

A milestone is rejected if it only adds scope without improving feel, readability or stability.

## Mechanical
- Responsive 360 movement, aim, recoil, hit reaction, traversal and vehicle transitions.
- Server authority survives latency and malicious client assumptions.

## Interactive
- Combat spaces expose multiple approaches and reactive world events.
- Rescue, breach, vehicle, boss and extraction beats are playable rather than decorative.

## Visual
- Original hero/enemy silhouettes.
- Consistent material/lighting language.
- Niagara/VFX readability under heavy combat.
- Nanite/Lumen used only where platform budgets support them.

## Cinematic
- Gameplay-to-cinematic transitions preserve player orientation.
- Boss reveals, vehicle entries and destruction beats are authored in Sequencer later, not hard-coded into combat logic.

## Online
- Dedicated-server soak tests.
- Reconnect and failure handling.
- Chat moderation controls before public scale.
- 8-player pass before 16/32-player expansion.
