# Jeddah Living World Event Matrix

| District | Low threat | Medium threat | High threat |
|---|---|---|---|
| Corniche | patrol | vehicle interception | helicopter pressure / evacuation |
| Al-Balad | security sweep | rooftop pursuit | district lockdown |
| Port | cargo inspection | convoy ambush | port lockdown / boat interdiction |
| Industrial | patrol | sabotage response | mech assault |
| Waterfront | marine patrol | fast-boat chase | boat interdiction + air support |

Events are authoritative server state. Visual Data Layers, crowds, VFX and Level Sequences are presentation driven from that state.
