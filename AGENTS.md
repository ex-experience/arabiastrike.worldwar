- Work from the approved development/feature branch.
- Do not invent binary `.uasset`/`.umap` placeholders.

- Preserve Saudi/Jeddah authenticity.
- Prefer vertical-slice proof over uncontrolled scope expansion.
- Enhanced Input is the target PC input architecture.
- Server-authoritative gameplay rules remain the multiplayer baseline.
- Keep code modular; use gameplay data assets where designer tuning is required.
- Every major feature must include QA and performance acceptance criteria.
